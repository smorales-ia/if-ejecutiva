## Limitación técnica registrada

`mcp__airtable__update_field` solo modifica `name`, `description` y `options.formula`. **No** permite cambiar el tipo de un campo (p. ej. date→dateTime) ni la precisión numérica. Cualquier cambio de tipo obliga a campo paralelo + deprecación + borrado diferido.
